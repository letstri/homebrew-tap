# letstri/homebrew-tap

Homebrew formulae for [druk](https://github.com/letstri/druk), a terminal code editor.

```sh
brew install letstri/tap/druk
```

`Formula/druk.rb` is generated by `scripts/formula.ts` in the druk repository and
committed here by that repository's release workflow — every release replaces it with one
whose checksums match the archives that release actually uploaded. Do not edit it by hand:
the next release overwrites it.

The formula installs the prebuilt binary from the GitHub release. Nothing is compiled, so
installing druk this way needs neither Bun nor Node.
